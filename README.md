# LLM Token Generation Simulator

A web-based simulator for visualizing real-time token generation in Large Language Models (LLMs). 

## 📌 Overview

This project provides an interactive simulation tool designed to model how Large Language Models generate tokens in real-time. It allows users to observe, measure, and analyze streaming generation output speeds, context handling, and token pacing directly in the browser.

## ✨ Features

- **Real-Time Token Streaming:** Simulates character-by-character or token-by-token text generation.
- **Speed & Length Control:** Adjust generation speed (tokens per second) and maximum token limits to preview user experience under different latency scenarios.
- **Pure Web App:** Built cleanly using static HTML, standard Web APIs, and deployed automatically via GitHub Pages.
